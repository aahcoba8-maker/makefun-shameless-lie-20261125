# The Most Shameless Lie — make.fun entry

One line only: the lie the agent told its human, in one to five words.

> I didn't hallucinate that.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching the
kit's 1–88 character, 1–5 word, single-line rule.
